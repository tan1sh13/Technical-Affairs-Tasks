Features
Countdown Timer
•	Displays the remaining time until the event begins.
•	Updates automatically every second.
•	Implemented using JavaScript Date objects and setInterval().
Event Schedule
•	Displays the list of events in a table format.
•	Structured using HTML tables.
•	Styled using CSS for readability and responsiveness.
Registration Form
Collects:
•	Name
•	Email Address
•	Roll Number
•	Branch
Form validation includes:
•	Email format validation
•	Roll number validation in the format:
CSxxxxxxx
Example:
CS1234567
Submitted data is displayed in the browser console.

Input Validation
Email Validation
Accepts valid email addresses such as:
abc@gmail.com
student123@yahoo.com
Rejects invalid formats.
Roll Number Validation
Roll numbers must follow the pattern:
CSxxxxxxx
Examples:
CS1234567
CS7654321
Invalid examples:
23BCE001
cs1234567
CS123
Implemented using regular expressions in JavaScript.
